# Share, export, and reading

A public share link is a Pro page anyone with the link can open. Costs and keys stay off unless you tick show costs. Nothing is posted until you copy the link.

Under a finished answer, Public link (Pro) makes that page. In Settings, Share, save an https address first if you want the link to open off this computer. Without that address the link stays on this computer. Revoke removes it. The live share link is still there for a recording on this computer.

Export a finished answer as a PDF or a Word document. Headings, bold text, and lists stay in the file. Export is part of Pro. Download PDF and Download Word sit under the answer. Keys are left out of the file. The download is yours. Nothing is sent.

Industry packs cover real estate, mortgage, credit repair, and creators. Credit repair follows CROA and does not promise a score change. Outbound text stays a draft. Open them under Pro prompts, Industry packs. A missing fact stops the prompt and asks. Real estate does not promise a sale price or a closing date, and it does not steer. Mortgage does not guarantee a rate, an approval, or a payment. Creators do not promise views or income, and a sponsored script says it is an ad.

Settings, Reading, adds a text size and a high-contrast mode. Read aloud is on an answer and speaks only when you click it. Click again to stop. If this window has no speech, the button says so.

Name an imported ChatGPT or Claude conversation in the chat and Meldmind uses that conversation as context. Put the name in quotes, for example: use "Tagline ideas for a bakery". Other imported chats stay out. Import the export on the History tab first. The file is read on this computer and is not uploaded.
