# Updates

This note shows once after an update. Take the tour again any time from Help, and from the Settings menu.

Check for updates is on the Help page and in Settings. The tray menu has it too. When a newer version is ready, the app says Update available. On the desktop, Install now (or Update and restart) downloads it. Nothing downloads until you click. Later dismisses the banner until the next version.

Your settings, keys, and projects stay in place across an update. The portable build does not update itself. Use Check for updates in the installed app.
