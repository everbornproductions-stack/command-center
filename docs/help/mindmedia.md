# MindMedia

MindMedia is in Create. Everything Meldmind makes for you can be kept here, in one list, whichever project it came from. Work that has no project goes to Unfiled.

- Left side: All media, Unfiled, and one entry for each project.
- Search by name, words, or prompt. Filter by type (Images, Video, Audio, Text, Sites, Files) or by status.
- Click a card to open it. You can rename it, add tags, change its status (Draft, Review, Approved, Published), move it to another project, download it, or delete it.
- Needs an ending: things you made but did not use yet. Choose Keep, Publish, or Discard.

## Finish

Press Finish under any result. A drawer opens with "Done? Choose where this goes." You can Copy, Print, Save as PDF, Save as Word, Save to MindMedia, or Publish. After every save you see where it went, with a link to open it.

## Publish

Publish always shows a preview first. If a place is not connected, it is a practice run: "Practice only, nothing is sent." Meldmind writes the result back on the item, with the link and the time.
