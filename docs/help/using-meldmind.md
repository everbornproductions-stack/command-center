# Using Meldmind day to day

## What changed

A share link made on this PC says this link only works on this PC. Copy the text or export a file.

Schedules use day buttons and a time. Presets include Weekdays at 5 pm and Fridays at 4 pm. Last run missed (app was closed) offers Run now.

Words from your never-say list, and guarantee when credit repair is on, are flagged before you copy or send.

Under the box, Meldmind says SSNs and account numbers are masked before sending.

Help includes Security and your data, plus a one-page security summary PDF.

MCP, OAuth, webhook, sender key, Handoff, and SCF mode use plain words. Each Handoff row says what happens.

The user guide says Meldmind. The installer is Meldmind-Setup.

Hint text is easier to read. Real estate and mortgage modes are coming. Marketplace stays capitalized.

Click Stop to cancel. Send says Still working while a run is going. Did not search the web when search is off. After 5 ratings, Meldmind says which AI it now prefers. A finished run can notify you in the background. You can type in any language. Nothing was charged on a failed run that cost $0.

## How it works

Share live link sits under an answer. On this computer the message is This link only works on this PC. Copy the text saves the answer. Export saves meldmind-share.md. A public address still copies the link.

Schedules no longer ask you to type a cron string for an ordinary week. Pick the days, set the time, or use a preset: Weekdays at 5 pm, or Fridays at 4 pm. If the app was closed past that slot, the schedule shows Last run missed (app was closed) and Run now. That catch-up is your click. Missed slots are not replayed on their own.

Before you copy or send, Meldmind checks your never-say list. When credit repair safety (SCF mode) is on, guarantee is flagged too. You can continue anyway.

Under the box, a line says what will be masked: SSNs and account numbers.

Click Stop to cancel a queued or running job. While a run is going, Send is disabled and reads Still working.

When search is off, the answer says Did not search the web.

After 5 ratings, Meldmind says which AI it now prefers for that kind of work.

If the window is in the background when a run finishes, Meldmind can show a desktop notification. It asks permission when you click Send.

A failed run that cost $0 says Nothing was charged.

Hint text is larger and easier to read. Under the credit repair safety setting, a note says real estate and mortgage modes are coming. Marketplace stays capitalized.

Plain words sit next to the short names. MCP (a plug-in connection). OAuth (sign in with the service). A webhook is a web address that receives a message. A sender key is a password for that address. Handoff means continue in another chat. SCF mode is credit repair safety. Each Handoff row says what happens: Meldmind copies a prompt and opens that page. You paste it. Meldmind does not type or send.

The user guide says Meldmind. The installer is Meldmind-Setup.

You can type in any language.
