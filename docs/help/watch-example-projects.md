# Watch example projects

Each Start a project type has a read-only sample. An example does not call an AI, does not spend credits, and does not become your project.

1. Open **Start a project** on the Command home screen, or from the Settings menu.
2. On the type card, click **Watch an example**. You can also click **How this works** on that screen for a short note.
3. The player walks the sample from the idea through the questions, the plan, each step, the deliverable, and the next steps. Use **Back**, **Next**, and **Pause**. **Open live view** plays the same example on the map.
4. **Download example** saves the sample as Markdown. The file starts with a line that it is example data.

A banner stays on screen: Example data. This is a sample project with made-up details. Nothing was sent and no AI was called. The chip says **Example data**. You cannot edit the sample or turn it into your project. Click **Start** on that type when you want a real one.

The six samples, and what they show:

| Type | Sample | What you see |
|---|---|---|
| Website | Harbor and Rye | Page list, copy, and a launch checklist for a fictional cafe |
| Music video | Lumen Park (Glass Orchard) | Concept, shot list, and prompts for a fictional song |
| Marketing campaign | Northline Outdoor | Offer, audience, channel plan, and drafts for a fictional shop |
| App/software | Fieldnote | Who it is for, must-have screens, and a build order for a fictional app |
| Business plan | Bright Kettle | A short plan with made-up figures marked as example data |
| Social media reels | Milo's Guitar | Hooks, captions, and what to film for a fictional teacher |

Do not publish them. Figures, names, and claims in a sample are not yours. In Simple, steps say an example AI. In Expert, the sample shows made-up routes so you can see how a plan reads. Either way, no AI is called.

To run your own, see the how-to for that type: Start a website, Start a music video, Start a marketing campaign, Start an app, Start a business plan, or Start social reels.

These samples are not desktop control. Letting Meldmind use an app on this PC, such as Google Antigravity, is a separate choice in setup and in Settings. See Apps on your desktop.
