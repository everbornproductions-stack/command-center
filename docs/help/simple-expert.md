# Simple and Expert

Simple and Expert. A new install starts in Simple: one chat box, and the council picks the AI.

The first setup step asks: Which mode do you want to start in? Simple is one chat box. Expert is every menu. You can change this later.

A Simple / Expert switch sits in the top bar on every screen. One click changes it. Your chats, projects, and keys stay put.

Simple shows Chat, Projects, Create, Help, and Settings. Create holds Pro prompts, images, media, and publishing. Settings is where a key goes. Help is the guides.

Expert keeps the debate, the scores, spend caps, the live map, marketplace, MCP, webhooks, and every menu. Anything Simple hides is one click away in Expert. Keyboard shortcuts keep working in both.

The chips under the chat box list only AIs you have connected. Demo stays there only until a real AI is connected.
