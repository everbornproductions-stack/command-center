# How to find and summarize a doc

Open **Docs and follow-up** in the Work menu.

Try saying: Find the Q3 proposal and summarize it

1. Type the name or a phrase and click **Find**.
2. Read the short summary. The first three sentences are kept.
3. Google Drive and Notion are searched only when they are already connected. Otherwise the search uses docs on this computer.
4. **Save a copy** writes a Meldmind doc on this computer. It does not write to Drive or Notion.

Find the Q3 proposal and summarize it. The search reads Google Drive and Notion when they are connected, and docs on this computer otherwise. Saving a copy stays on this computer.
