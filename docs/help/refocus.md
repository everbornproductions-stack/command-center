# Refocus

Refocus is in the Work menu.

Type a topic, such as music videos or half-done reels, and click Find. Meldmind reads saved chats, imported chats, project files, saved outputs, and Google Drive when Drive is already connected. It lists the matches from oldest to newest. Each row shows the source, the date, a short summary, and a status: finished, partial, or abandoned.

Find also looks on this PC: your Videos, Downloads, Desktop, Documents, Music, and Pictures folders, OneDrive, Google Drive for desktop (My Drive and Shared drives), and the project folders Meldmind knows about. It reads Claude folders and Claude Code sessions on this PC, Grok Bot results (including the Drive links it reported), and other connected agents. Each result shows who made it, such as Claude, Grok Bot, ChatGPT, or This PC. Any word in the topic can match a file name, a folder name, or the text of a small text file. Category words widen the match: music videos finds video and song files, and billing finds invoices, receipts, payments, and HighLevel.

While it searches, the Find button says Searching. When nothing turns up, Refocus lists every place it looked and offers Search more places, which looks deeper, on every drive, and at every file type. The app's own data folder is never searched.

Private chats are left out.

The complete version plan says what was kept, what was improved, and what is still missing. That plan is built on this computer. Nothing is sent when you click Find.

Rebuild it starts a mission that writes the stronger, complete version. The page lists who will read it first, the same list a council or mission shows. The full rebuild is part of Extreme. Finding the timeline is part of Pro. Free shows an upgrade note and does not search.

Meldmind remembers which sources and which AIs finished a rebuild, so a later Refocus can rank those higher. It stores the source kind and the AI id, not the chat text and not your keys.
