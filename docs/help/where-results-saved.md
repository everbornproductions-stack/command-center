# Where your results are saved

Open Create, then MindMedia. Every result you keep is there: answers, pictures, video, pages, and files. Search by a word from the name, or filter by type.

How things get there:

- Press Finish under an answer, then Save to MindMedia.
- Pictures, video and web pages you make are saved there for you.
- If an answer has code, Finish shows Save code as files. Each code block becomes its own file, with a zip you can download.
- Work with no project goes to Unfiled. You can move it to a project any time.

Lost something? Open MindMedia and look in Trash. Deleted items stay there for 30 days, and Restore puts them back.

Nothing is sent or posted from here without your click.
