# How to find a time and propose it by email

Open **Day plan**.

Try saying: Find 3 open 30 min slots next week for Ana

1. Type the person's name, email address, and how many minutes.
2. Busy blocks and local holds on this computer are skipped. Weekends are skipped. The search uses 9:00 to 17:00.
3. Click **Draft the options**. The draft lists the times.
4. Read the To, subject, and body. Edit them if you want.
5. Click **Send**. That click sends the text on screen. Until Gmail send is connected, the draft stays.

Nothing is booked. The other person still has to reply.
