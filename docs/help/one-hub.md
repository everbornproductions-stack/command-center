# One hub for all your AIs

Meldmind is one hub for the AIs you already pay for. You say what you want in plain words. Meldmind picks the best AI for that task.

It learns from the jobs you run on this computer. The choice gets sharper as you use it. When Who's best is in your menus, it shows which AI has been best at each kind of job.

This part is Free. You can try it from the chat box. Nothing is spent while you are still on the pretend AIs.
