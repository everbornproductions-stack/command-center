# Start a project

Start a project walks you from an idea to a finished deliverable. It is on the home screen (Command, or Chat in Simple mode) and in Help. The Settings menu has the same entry.

You pick one type:

- Website
- Music video
- Marketing campaign
- App/software
- Business plan
- Social media reels

## The six steps

1. **Describe the idea.** A sentence or two is enough.
2. **Clarifying questions.** Required questions must be answered. Optional ones can stay blank. The app does not invent a missing fact.
3. **The council builds a plan.** Several AIs agree a short list of steps. Nothing runs until you click Build it.
4. **Each step is routed.** The same router that handles Command picks the best AI for that step. Progress shows on the live view and the flow map. API chats do not appear in claude.ai, grok.com, or ChatGPT history. Watch the work here.
5. **Review and revise.** Read the deliverable. Say what should change and click Revise. Each revision is a click.
6. **The result.** Export a Markdown file, then follow the next steps. The file stays on your computer. Nothing is posted, emailed, or published.

## Simple mode and Expert mode

Simple mode is the default for a new install. It uses plain words ("a writing AI") and does not ask you to edit the plan.

Expert mode shows the model, the capability, and the route, and lets you edit a step's title and instructions before you click Build it. The Simple / Expert switch in the top bar decides which one you see. The steps themselves are the same.

## Watch an example

Watch an example uses labeled example data and does not call an AI. Each type has a finished sample: Harbor and Rye, Glass Orchard, Northline Outdoor, Fieldnote, Bright Kettle, and Milo's Guitar. The sample is read-only. Start a project when you want your own.

## What a click does

Asking the council, building the steps, revising, and exporting each wait for a click. Watching an example is also a click. Turn on demo mode in Settings, or add an API key, before a real project asks the council. Demo mode uses pretend AIs and does not spend credits.
