# How to suggest a connection or idea

The box is in **Settings**, on the What's new card, and on the connections page when nothing is connected yet.

Try saying: I want a connection for my calendar

1. Write the idea. Pick connection, action, bug, or other. An email for a reply is optional.
2. The version and OS box is on by default. It does not include chat.
3. Click **Show exactly what is sent** and read the note.
4. Click **Send**. Until that click, nothing leaves this computer.
5. If delivery is not set up, the note stays on this computer. The page says: Thanks, Chris reads these.

Suggest a connection or idea from Settings. You read the exact note, then click Send. Chat is not included.

Do not put a password, an SSN, or a key in the box.
