# Stay fast on an older PC

Meldmind opens the home screen first. Other pages load when you open them. A big tool such as speech-to-text or a game template is not inside the installer.

## Light mode

Open Settings, then Performance. Tick Light mode for an older PC.

Light mode slows the checks that run in the background. It turns off extra motion. Extra panels stay off the home screen until you leave Light mode and open Meldmind again. Panels you already opened in this visit can stay in memory until you quit.

Your chats, keys, and projects stay put. A scheduled result still waits until you click Approve. Nothing is sent on its own.

## Add-ons

Settings, then Performance, lists Add-ons. Each row shows a size, such as about 150 MB.

The tool is not downloaded yet. Click Install only if you want that copy on this PC. The button shows the size. That click is the approval. Remove deletes the copy from this PC.

If you have not installed the tool, Meldmind uses a connected AI for that job when it can. A local copy is optional.

## What keeps running

While Meldmind is open it can check schedules, model prices, and a few other slow jobs. Those share one timer. They pause when the window has been minimized for a minute, or when this PC is on battery, or when nobody is using the app. Light mode makes the same jobs wait longer.

The update check in the desktop app still runs. That way a stuck copy can still install an update.
