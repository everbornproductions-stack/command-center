# How to use What's new

Open **Settings**. The What's new panel is there. After an update, a card also lists new connections and actions.

Try saying: What needs me today in all my inboxes?

1. Read each row. A connection points at the checklist. An action has Try it.
2. Try it runs a sample on this computer. It does not send, post, or connect.
3. Skip hides that row for good.
4. Remind me later waits 3 days, then 7 days. After that the row moves to Settings and stops asking.
5. Skip all clears the card. Google Calendar sign-in still starts only from the checklist row.

What's new offers each new connection and each new action. Try it runs a sample and does not send. Skip hides that row. Remind me later waits 3 days, then 7 days, then the row moves to Settings. Google Calendar sign-in still starts only from the checklist row. Nothing connects from the What's new card.

The version note that lists this release is a different card. This one is about new connections and actions.
