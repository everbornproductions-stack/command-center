# Shared learning

Meldmind is an Everborn product. A new install leaves **I am willing to share anonymous track records** off until you tick it. An install that already had it on keeps it on. You can change this any time in Settings.

Meldmind learns from every job you run. Anonymous track records help it pick the best AI for everyone.

## What we share

We share only anonymous track records: the task type, which AI, and the score. We never share prompts, content, or keys. We do not share your name, your account, or the text of a chat.

While the box is clear, this note appears: Meldmind learns from the community. With this off, your jobs won't help make it smarter for everyone, but you'll still benefit from what others share.

You can change this any time in Settings. On **Who's best**, tick or clear **I am willing to share anonymous track records**.

**Show what would be shared** lists the anonymous totals on this computer. This version does not send them.

Your own router still learns on this computer when **Learn from every job** is on. That local record is separate. Shared learning is only the anonymous track records above.

Anonymous usage counts are a separate switch in Settings: **Share anonymous usage counts to help improve Meldmind**. That switch is off on a new install until you turn it on. It sends a random install id, the version, the operating system, your plan, and feature counts. It does not send prompts, chats, emails, or files. It is not the track records above. This version still does not send track records.
