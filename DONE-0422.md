# DONE-0422: Safety check (item SAFETY)

## What changed
- `server/safety-check.js` (new): `runSafetyCheck({files|dir, now})`, `applySafetyFix({files, fixId})`, optional `runSafetyCheckOsv({osvFetch})` (off unless passed; gets names and versions only). Scanners: secrets (key shapes, private key blocks, password/secret assignments, entropy, .env lines), dependencies (package.json, package-lock.json, requirements.txt), code rules (eval/new Function, innerHTML/document.write, exec with template string, http form posts, hard-coded admin password, CORS * with credentials), site checks (Content-Security-Policy tag, mixed content). Secret values are never stored or returned (first 3 chars + `****`). Groups, test-file downgrade to low, auto-ignore with a stated reason, TL;DR per group. Light: red only for a LIVE secret, amber for real findings, green otherwise (low notes do not change the light).
